# Topic 4 LMS Assessment
## Tracing, Logging and Debugging Agentic Loops

## 1. Assessment Overview

This assessment evaluates your ability to inspect, debug, repair, and validate an AI Agent workflow by analyzing execution history, execution telemetry, reasoning loops, tool failures, and prompt guardrails.

## 2. Assessment Objective

Demonstrate the ability to diagnose workflow failures, implement prompt-based error handling, optimize execution behavior, and validate successful workflow completion.

## 3. Prerequisites

- Review the Requirement Document.
- Review the Implementation Guide.
- Complete Topics 1–3.
- Access to an active n8n instance with configured LLM credentials.
- GitHub account for source code submission.

## 4. Assessment Tasks

- Exercise 1 – Execute the broken workflow.
- Exercise 2 – Inspect Execution History.
- Exercise 3 – Analyze execution telemetry.
- Exercise 4 – Identify configuration issues.
- Exercise 5 – Repair the workflow using prompt guardrails.
- Exercise 6 – Validate the repaired workflow.
- Exercise 7 – Compare performance before and after repair.
- Exercise 8 – Complete the end-to-end debugging mini project.

## 5. Practical Assessment Checklist

- [ ] Broken Workflow Executed
- [ ] Execution History Reviewed
- [ ] AI Agent Inspected
- [ ] HTTP Tool Failure Identified
- [ ] Execution Timings Reviewed
- [ ] Workflow Configuration Analyzed
- [ ] System Prompt Updated
- [ ] Error-Handling Guardrails Implemented
- [ ] Workflow Re-executed
- [ ] Graceful Error Handling Verified
- [ ] Tool Retry Prevented
- [ ] Performance Comparison Completed
- [ ] End-to-End Debugging Completed

## 6. Assessment Success Criteria

- Diagnose workflow failures accurately.
- Analyze execution history and telemetry.
- Implement effective prompt guardrails.
- Prevent repeated tool execution.
- Validate successful repaired workflow execution.
- Submit all required deliverables.
